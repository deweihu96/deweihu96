# Hi, I'm Dewei 👋

Postdoc at the Novo Nordisk Foundation Center for Basic Metabolic Research, University of Copenhagen, working with [Simon Rasmussen](https://scholar.google.com/citations?user=fh52UsQAAAAJ) and [Tune Pers](https://scholar.google.com/citations?user=S-ZRIq4AAAAJ).

- 🤖 We work on **AI agents and single-cell foundation models for obesity**.
- 🧬 My PhD, with Simon Rasmussen and [Lars Juhl Jensen](https://scholar.google.com/citations?user=zXAyIo0AAAAJ), was on representation learning for biological networks and multi-omics integration.
- 🕸️ I built cross-species protein embeddings on top of the [STRING](https://string-db.org) database.
- 📊 I integrated metabolomics, proteomics, and protein interaction networks at population scale to study complex disease.
- 🇩🇰 Based in Copenhagen.

### Selected repositories

- [**SPACE**](https://github.com/deweihu96/SPACE) ![stars](https://img.shields.io/github/stars/deweihu96/SPACE?style=social): cross-species protein embeddings, now part of STRING v12.0 and 
- [**net2rank**](https://github.com/larsjuhljensen/net2rank) ![stars](https://img.shields.io/github/stars/larsjuhljensen/net2rank?style=social): molecular maps of disease from omics data and network embeddings
- [**SLIM**](https://github.com/RasmussenLab/SLIM) ![stars](https://img.shields.io/github/stars/RasmussenLab/SLIM?style=social): a small linear model with STRING embeddings for virtual cell perturbation
- [**AugMent**](https://github.com/RasmussenLab/AugMent) ![stars](https://img.shields.io/github/stars/RasmussenLab/AugMent?style=social): contrastive alignment that transfers proteomic disease signals to metabolomics
- [**virtual-cell-wiki**](https://github.com/deweihu96/virtual-cell-wiki) ![stars](https://img.shields.io/github/stars/deweihu96/virtual-cell-wiki?style=social): an AI-readable knowledge base on virtual cell models
